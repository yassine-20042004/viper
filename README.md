# Personal Finance Tracker

![Finance Tracker Demo](demo.gif) <!-- You can add a demo gif later -->

A command-line personal finance management system that helps you track accounts, transactions, budgets, and financial goals with persistent data storage.

## Features

- **User Management**
  - Secure registration and login
  - Profile customization
  - Password changes

- **Account Tracking**
  - Multiple account support (checking, savings, credit)
  - Balance tracking and updates
  - Transaction history

- **Financial Tracking**
  - Income and expense recording
  - Categorization system
  - Budget creation and monitoring
  - Financial goal setting

- **Reporting**
  - Monthly summaries
  - Spending by category
  - Income vs. expense analysis
  - CSV export capability

- **Data Management**
  - Automatic JSON data storage
  - Persistent between sessions
  - Backup and restore functionality
